# Sitio web REDLEAD

## Alcance
Construir un sitio institucional de tres páginas en español: Inicio, Sobre Nosotros y Contacto, con navegación fija y pie de página compartido.

## Diseño
- Aplicar la paleta roja, verde azulado, naranja/dorado y fondos blancos cálidos solicitada.
- Usar el logotipo adjunto como marca principal y crear desde él el favicon.
- Mantener una estética moderna, limpia, juvenil y accesible, con tipografía sans-serif de alto impacto.
- Incorporar fotografías auténticas de jóvenes latinoamericanos en contextos de estudio, tecnología y colaboración virtual.

## Páginas
- **Inicio:** portada, cinco herramientas para destacar, cinco resultados del programa, tres beneficios clave, tres pilares y cierre de inscripción con redes sociales.
- **Sobre Nosotros:** origen como Community Project de KECTIL 2026, definición, misión, objetivo y pilares.
- **Contacto:** texto de inscripción, formulario visual sin envío real, enlace reservado `#inscripcion` y redes sociales.

## Comportamiento
- Navegación adaptable a escritorio y móvil.
- Enlaces internos entre las tres páginas.
- Botones de inscripción dirigidos al marcador `#inscripcion` de Contacto.
- Controles del formulario claramente etiquetados y estados interactivos accesibles.

## Detalles técnicos
- Crear componentes compartidos para cabecera, pie, redes sociales y elementos visuales repetidos.
- Definir todos los colores y estilos de marca mediante el sistema global de diseño.
- Añadir metadatos únicos para cada página.
- Optimizar el logo para uso web mediante la CDN de recursos y crear un favicon local de 64×64.
- Verificar la presentación en escritorio y móvil, además del estado de compilación.
